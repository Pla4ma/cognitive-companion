## Screenshot Strategy

### Screenshot 1: Hero — "Stuck?"
**Visual:** Dark background, large text "Stuck?" fading into "Let's fix that." Below: a single big button saying "2-Minute Rescue" in warm accent color.
**Purpose:** Communicate the core value prop in 2 seconds. Stop the scroll.

### Screenshot 2: Rescue in Action
**Visual:** Split view showing a rescue session in progress. Left: the timer at 1:42. Right: step-by-step micro-actions ("Open the document. Just read the first sentence."). Warm, non-threatening UI.
**Purpose:** Show what actually happens — concrete, not abstract.

### Screenshot 3: Brain Dump
**Visual:** A messy cloud of floating words/tasks ("call dentist", "that email", "laundry") being captured into a clean list. Satisfying visual transformation.
**Purpose:** Demonstrate the mental clutter clearing feature.

### Screenshot 4: Before-Scroll
**Visual:** Phone screen with social media about to open, overlay saying "Before you scroll — is there a 2-minute task waiting?" with quick action buttons.
**Purpose:** Show the unique scroll-intervention feature. Creates curiosity.

### Screenshot 5: Momentum Without Streaks
**Visual:** Calendar view with soft, warm dots showing activity — but NO red gaps, NO "you broke your streak" messaging. Text overlay: "Patterns, not pressure."
**Purpose:** Differentiate from every streak-based app. Speak to the audience that's been burned by gamification.

## Preview Video Concept

**Duration:** 15 seconds (auto-play in search results)

**Script:**
```
0s-3s:  Dark screen. Text types out: "You're avoiding something right now."
3s-6s:  Screen brightens. Phone notification: "INTENT: 2-minute rescue?"
6s-9s:  User taps. Quick montage of rescue steps: brain dump → micro-action → timer.
9s-12s: Timer completes. Gentle celebration. Text: "You started."
12s-15s: Logo + "INTENT — Beat Procrastination. Free."
```

**Tone:** Calm, warm, slightly confrontational (in a kind way). No upbeat music — use ambient/lo-fi. No stock footage.

## Rating Prompts Strategy

### When to Prompt
1. **After 3rd completed rescue session** — user has demonstrated engagement and experienced value
2. **After first "momentum day"** (2+ sessions in one day) — peak positive emotion
3. **Never after:** a skipped session, app close within 10 seconds, or during an active rescue

### Prompt Copy
```
"Hey — you've used INTENT [X] times. Would you mind rating it? It helps other stuck brains find us."

[Rate INTENT]  [Maybe Later]  [No Thanks]
```

### Rules
- Maximum 3 prompts per user per year
- "No Thanks" = never ask again
- "Maybe Later" = 30-day cooldown
- Reset prompt count after each app update (new version = new chance)

