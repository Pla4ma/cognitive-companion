## Principles

1. Every feature must increase the "holy shit this gets me unstuck" feeling
2. If it doesn't help catch the drift moment, it doesn't ship
3. Privacy is not a feature — it's the foundation
4. Deterministic first, AI enhances, never blocks
5. No shame, ever
6. Works offline, always
